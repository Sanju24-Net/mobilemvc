# 📱 Mobile Store MVC Project

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap

## Features
- Product CRUD (Create, Read, Update, Delete)
- Image Upload
- Search Functionality
- Login System
- Responsive UI

## Project Output
Run in Visual Studio using IIS Express
